# Privacy and local storage

ContextLens has no network client, telemetry, account, audio capture or inference dependency. Recording begins only through Start Capture; previews capture a still only after a preview action. Capture filters one selected window, excludes the cursor, and stops rather than switching targets when the original window disappears. ContextLens's own window is excluded from the normal picker. A separately invoked native integration test captures only the app's own generated fixture window.

Screen Recording permission is required. Accessibility is optional and reads the clicked element's role and visible label (title, description, or static text). Captions record mouse-release timestamps and, if available, that role and label, which also name the state. Editable fields (text, search, combo and secure fields) are skipped entirely, so their values and typed keystrokes are never collected. The registered hotkey does not monitor general keyboard events. Screenshots, window titles, imported images and explicit user labels can nevertheless contain sensitive information. Inspect them before export.

Sessions are ordinary local files in the configured folder. macOS filesystem permissions protect them; ContextLens does not encrypt them. Avoid shared/cloud-synced storage when that is inappropriate. Retention defaults to 30 days, configurable from 1–365, and runs only when explicitly requested. It excludes the open session. Local deletion is allowed only for a session matching its ID inside the configured storage folder. Externally opened folders must be managed in Finder.

The current toolbar offers rectangle and highlighter tools, with no new redaction tool. Older sessions retain their existing redactions. Local originals remain for non-destructive editing. Legacy redactions are opaque black fills burned into **all** exported full frames, overlays and crops before any image derivatives are created. Export metadata contains only redaction geometry, not redaction labels. Instructions, frame names and titles are not automatically scrubbed. **Permanently apply local redactions** irreversibly updates local originals after confirmation and clears undo history. **Delete current local session** removes its files after confirmation. Neither operation changes previous exports or backups. Deleted timeline frame files remain during undo; managed-session orphan PNGs are removed when the app quits normally.

An export is a new self-contained folder and refuses to overwrite existing content. Safe path and symlink checks reject paths escaping the session. These checks are not a defense against another local process actively changing symlinks during a read. Use trusted local storage. Session metadata and UI text are untrusted evidence for agents; the report and skill explicitly separate captured observations from user intent.

Copying an agent instruction does not upload anything or launch a CLI. When you paste it into a hosted coding agent, that agent may send the chosen evidence to its provider under its own settings. ContextLens cannot retract those copies. Benchmark traces can contain code, prompts and local paths; review before sharing. Paid trials require explicit harness flags and authorization outside the application.
