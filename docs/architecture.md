# Architecture

`ContextLensCore` contains Codable version-1 sessions, normalized annotations, path/bounds validation, a pure streaming frame selector, and deterministic Markdown reports. It imports Foundation only. Frames have stable IDs; issue IDs monotonically increase, including across undo. Review order is separate from recorded timestamps.

`ContextLensCapture` lists ScreenCaptureKit windows excluding ContextLens, desktop surfaces and tiny windows. Capture binds a window ID and owning process ID; each sample refreshes window metadata and resolves that same identity. Movement/resize use the current content filter bounds and point-to-pixel scale. Missing or off-screen windows stop safely. There is no display fallback. macOS 14's SCScreenshotManager captures one still at a time with `SCContentFilter(desktopIndependentWindow:)`, no cursor and no window shadow. See [Apple's content filter](https://developer.apple.com/documentation/screencapturekit/sccontentfilter/init(desktopindependentwindow:)) and [screenshot manager](https://developer.apple.com/documentation/screencapturekit/scscreenshotmanager).

The main actor owns UI/permissions and a single sequential sampling Task (~4 Hz plus processing cost). A separate `CaptureProcessor` actor downsamples to at most 240×240 luminance, compares and encodes only committed frames. There is no unbounded candidate queue or sampled-frame disk stream. It retains one latest full-size image and small comparison buffers. Stop waits for in-flight work and flushes a pending distinct state, including on termination. Screen capture enumeration/encoding costs are not included in the comparator microbenchmark.

The selector counts pixels differing by at least 18 luminance levels. Global change fraction and maximum 10×10-tile regional fraction jointly generate candidates. Capture offers Low and High only, defaulting to High. Low uses 6% globally or 36% of one tile with at least twelve changed comparison pixels; High uses 0.8% globally or 8% of one tile with at least three changed pixels. The original balanced thresholds are retained internally only for replaying archived benchmark sequences. Candidates settle for 350 ms; a continuously moving state is committed at a 1500 ms upper bound. Manual snapshots bypass deduplication. Resize changes are always candidates. Dedup compares to the last committed state, preserving meaningful A→B→A sequences. It is not semantic UI understanding; very small/low-contrast controls can be missed and continuously animated content can still consume the frame limit.

Mouse-release captions apply only when the selected application is frontmost and the topmost layer-zero window under the pointer matches the selected window ID. Optional Accessibility reads role and visible control labels, skipping editable fields; it never reads text-field values or keyboard input. A Carbon hotkey registers ⌘⇧S without observing a keyboard event stream. Mouse events do not imply an intended change or force identical images into the session.

`ContextLensImaging` uses CoreGraphics/ImageIO for pristine PNGs, overlays and padded crops. Editor geometry maps the actual aspect-fit image area to normalized top-left coordinates, accounting for letterboxing. The current toolbar creates rectangles and freehand highlights. Legacy arrows retain endpoint order when reopened; highlight strokes retain points. Region edits transform their points. Export first burns solid black redactions, then produces safe full frames, per-issue overlays and context-padded crops. The same renderer supplies the editor and exported overlays.

The exporter stages a complete package beside its destination, validates source dimensions, sanitizes metadata paths and excluded frames, and renames the finished folder atomically. It refuses to overwrite an existing export. Relative paths remain portable. No original unredacted image is copied to an export. Local sessions retain originals until explicit permanent redaction or deletion.

`ContextLensApp` supplies capture, timeline, annotation, export and privacy views. Session JSON writes are atomic. Undo is limited to 50 metadata states through the tested Core SessionHistory. EditorRenderRequest excludes note/task/name/selection changes from image invalidation. A serial ImagePipeline actor decodes away from the UI thread, retains one selected full-size source, and bounds thumbnail caching to 32 MiB at ≤520 pixels. Cancelled/superseded editor work cannot publish over a new selection. Horizontal screenshot strips are lazy and thumbnails release view references when they disappear. The `.app` has a stable bundle identifier for TCC and uses an available development identity, falling back to ad-hoc signing. It is not notarized for distribution.

ExportPlan applies the two independent export filters once for the preview and package. It preserves all annotated frames, uses exact decoded-pixel fingerprints to exclude unannotated duplicates, and keeps stored sessions unchanged. New manifests use version 2 with compact annotation summaries; precise geometry stays in session metadata.

The exported context brief is self-contained, with exact user instructions and one full-resolution annotated overview per marked state. A single-mark overview reuses the existing per-issue PNG; multiple marks share one additional render. Full review history lives in an optional timeline. Crops, individual overlays, redacted full frames and machine metadata remain available without mandatory initial reads. See lean handoff (local-only evidence `lean-handoff.md`) for preservation checks and pending agent validation.

`contextlens-cli` validates, replays, demonstrates, profiles and exports sessions using the same production modules. `Integrations/contextlens/SKILL.md` defines portable evidence consumption. The app copies instructions; direct CLI execution/MCP are intentionally deferred.

The benchmark's Python harness and Node/Playwright evaluator are independent of application internals. The browser fixture capture utility drives the CLI's production replay/export path; it never changes production code. Provider traces are normalized separately. No inferred intent or model invocation is required to compile a package.

CaptureProcessor ignores stale samples before replacing pending data and commits selector/sequence changes only after PNG persistence succeeds. Export cancellation is checked before/within staging and before publication. Geometry and luminance-buffer sizes are validated before drawing/allocation. Unified logs contain static operation messages and numeric timings/counts only; see [diagnostics](diagnostics.md).
